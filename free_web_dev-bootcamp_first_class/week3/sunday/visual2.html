CSS Flexbox: One-Dimensional Layouts

Flexbox is designed for one-dimensional layouts, meaning it can handle either rows or columns at a time. It excels at distributing space and aligning content within a container, making it perfect for component-level layouts like navigation bars, cards, and form controls.

Flex Direction

The flex-direction property defines the main axis along which flex items are placed. This determines the direction items flow in the container.

.container { display: flex; flex-direction: row; }

Justify Content

The justify-content property aligns flex items along the main axis (defined by flex-direction). It controls how extra space is distributed between items.

.container { display: flex; justify-content: flex-start; }

Align Items

The align-items property defines how flex items are laid out along the cross axis (perpendicular to the main axis). It's particularly useful for vertical alignment.

.container { display: flex; align-items: stretch; }

CSS Grid: Two-Dimensional Layouts

CSS Grid is a powerful two-dimensional layout system that handles both rows and columns simultaneously. It's ideal for complex page layouts, card grids, and any design that requires precise control over both dimensions.

Basic Grid Layout

Define columns and rows using grid-template-columns and grid-template-rows. The fr unit represents a fraction of the available space.

.container { display: grid; grid-template-columns: 1fr 1fr; grid-template-rows: auto auto; }

Grid Areas

Use grid-template-areas to create named areas and place items using grid-area. This approach makes complex layouts more readable and maintainable.

.container { display: grid; grid-template-areas: "header header header" "sidebar content content" "footer footer footer"; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .content { grid-area: content; } .footer { grid-area: footer; }

Advanced Grid: Auto-fit & Minmax

Create responsive layouts with repeat(auto-fit, minmax()) that automatically adjusts to container size. Auto-fit will create as many tracks as can fit without overflowing.

150px
.container { display: grid; grid-template-columns: repeat(auto-fit, minmax(150px, 1fr)); }

Next Steps in Your CSS Journey

Now that you've experimented with Flexbox and Grid, you're well on your way to mastering modern CSS layouts. Remember that these systems work well together - use Flexbox for component-level layouts and Grid for page-level layouts.
