CSS Flexbox

Flexbox is a one-dimensional layout method for arranging items in rows or columns. It's perfect for component-level layouts where you need to align items in a single direction.

Flex Direction

The flex-direction property defines the main axis along which flex items are placed.

.container { display: flex; flex-direction: row; }

CSS Grid

CSS Grid is a two-dimensional layout system that handles both rows and columns. It's ideal for page-level layouts and complex component arrangements.

Basic Grid Layout

Define columns and rows using grid-template-columns and grid-template-rows.

.container { display: grid; grid-template-columns: 1fr 1fr; grid-template-rows: auto auto; }

Grid Areas

Use grid-template-areas to create named areas and place items using grid-area.

.container { display: grid; grid-template-areas: "header header header" "sidebar content content" "footer footer footer"; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .content { grid-area: content; } .footer { grid-area: footer; }

Create responsive layouts with repeat(auto-fit, minmax()) that automatically adjusts to container size.
