## Part 2: Practical Task

1. Create a folder named **`week1`**.  
2. Inside the folder, create a file named **`assignment.html`**.  
3. In `assignment.html`, recreate the structure of the HTML page shown in the reference image.  

### Requirements:
⚠️ Do not copy code directly from any website or ChatGPT. Use resources only for **understanding**.  

- Include a **form**.  
  *Hint: Look up form examples on [W3Schools](https://www.w3schools.com).*  

- Include a **list**.  
  *Hint: Use ordered (`<ol>`) or unordered (`<ul>`) lists.*  

- Add **two images**:  
  - One image from an **external source** (the internet).  
  - One image stored **locally** in your project folder.  

- Embed a **YouTube video**.  
  *Hint: Use the “Embed” option from YouTube to copy the code.*
