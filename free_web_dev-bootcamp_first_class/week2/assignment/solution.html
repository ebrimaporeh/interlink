Semantic HTML5 Elements

Understanding Semantic HTML

Semantic HTML introduces meaning to the web page rather than just presentation. It makes web content more accessible and helps with SEO.

Did You Know?

Using semantic elements can improve your website's accessibility for screen readers and other assistive technologies.

Here's how we've used semantic elements in this page:

  • <header> for the introductory content
  • <nav> for the navigation menu
  • <main> for the primary content
  • <section> to group related content
  • <article> for self-contained compositions
  • <aside> for tangential content
  • <footer> for the page footer
