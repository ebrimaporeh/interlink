# Assignment: Build a Comprehensive HTML Page

## 🎯 Objective  
Create a complete HTML page that demonstrates your understanding of both basic and advanced HTML elements **without using any CSS or JavaScript**.

---

## ✅ Requirements  

Your HTML page must include all of the following elements:

### 1. Advanced Forms  
- A form with at least **5 different input types** (text, email, password, tel, date, color, range, etc.)
- Validation using the **`pattern` attribute** with appropriate **`title` attributes**
- A **`textarea`** for longer input
- A **dropdown `select` menu**
- A **date picker**
- Proper use of **`fieldset`** and **`legend`** for grouping
- Appropriate **`autocomplete`** attributes

### 2. Complex Tables  
- A table with **`thead`**, **`tbody`**, and **`tfoot`** sections
- Use of **`rowspan`** and **`colspan`** attributes
- At least **4 columns and 5 rows of data**
- Proper use of **`scope`** and **`caption`** attributes for accessibility
- **`summary`** attribute for table description

### 3. Multimedia Elements  
- A **`<video>`** element with multiple **`<source>`** formats and fallback text
- An **`<audio>`** element with multiple **`<source>`** formats and fallback text
- Proper use of the **`controls`**, **`preload`**, and other media attributes
- Accessible descriptions using **`aria-describedby`**

### 4. HTML5 Semantic Elements  
- Proper use of:  
  - `<header>`  
  - `<nav>`  
  - `<main>`  
  - `<section>`  
  - `<article>`  
  - `<aside>`  
  - `<footer>`  

### 5. Other HTML5 Elements  
- **`<details>`** and **`<summary>`** for expandable content
- **`<progress>`** and **`<meter>`** for displaying values
- An **`<iframe>`** embedding an external page with proper **`title`** attribute

### 6. Accessibility Features  
- Proper use of **`alt` attributes** for images (when present)
- **ARIA attributes** where appropriate (`role`, `aria-labelledby`, `aria-describedby`)
- Use of **semantic HTML** for screen readers
- Proper **form labeling** and **fieldset/legend** usage
- **Table accessibility** features (scope, caption, summary)

---

## 📌 Instructions  
- Do not include **CSS or JavaScript**
- Ensure your HTML is **well-structured** and uses **semantic tags** correctly
- Your final page should be long enough to demonstrate mastery of the elements listed above
- Include proper **document structure** with `<!DOCTYPE>`, `<html>`, `<head>`, and `<body>`
- Add appropriate **meta tags** for charset and viewport
- Ensure all interactive elements are functional without CSS/JS
